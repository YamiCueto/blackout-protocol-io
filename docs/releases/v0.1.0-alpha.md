# BLACKOUT PROTOCOL v0.1.0-alpha

> **First Public Playable Release — Tactical Web-Based FPS**  
> Play instantly in browser: [https://yamicueto.github.io/blackout-protocol-io/](https://yamicueto.github.io/blackout-protocol-io/)

---

## Overview

We are excited to present the first public alpha release of **BLACKOUT PROTOCOL (v0.1.0-alpha)**, a tactical first-person shooter running natively in the browser on Three.js r160 and vanilla JavaScript ES Modules.

This release establishes the core game engine, real-time procedural rendering pipeline, full-featured 3D lobby, procedural character animation, and two distinct gameplay modes without external build tools or bundled asset dependencies.

---

## Key Highlights

### 1. AAA-Inspired 3D Tactical Lobby
- Layered interface architecture inspired by *Call of Duty: Warzone* composition.
- The 3D hangar and procedural operator occupy the primary view without visual obstruction from central UI blocks.
- Real-time idle animations: sinusoidal thoracic breathing, head scanning, and subtle camera drift.
- Dynamic lighting setup with high-contrast cyan rim lighting, soft directional key lighting, and ambient fill.
- Seamless camera framing transitions (`setLobbyView`) between Play, Operator, and Loadout tabs.

### 2. Procedural 3D Operator ("Spectre")
- Fully articulated humanoid soldier constructed entirely from geometric primitives and procedural materials.
- Equipped with a FAST ballistic helmet, NVG mount shroud, tactical goggles with active thermal glow, plate carrier vest with MOLLE magazine pouches, and thigh holster.
- Real-time camouflage switcher in the Operator tab:
  - **Urbano Nocturno:** Low-visibility slate urban uniform with red thermal optic.
  - **Operaciones Negras:** High-stealth charcoal spec-ops scheme with amber visor.
  - **Reconocimiento:** Tactical forest reconnaissance camouflage with cyan optic.

### 3. FPS Combat Mechanics
- **Aim Down Sights (ADS):** Precision zoom with smooth dynamic FOV transitions.
- **Ballistic Simulation:** Recoil impulse, automatic weapon recovery, hipfire spread penalties, and bullet tracers.
- **Audio-Visual Feedback:** Bodyshot and headshot hitmarkers, animated lethal headshot banner, and 360-degree directional damage indicator ring.
- **Audio Synthesizer:** 100% procedural sound effects generated in real time with the Web Audio API (gunfire, dry-fire clicks, reloads, pain, and explosions).

### 4. Playable Game Modes
- **WAVES (Survival):** Supervivencia pura contra oleadas crecientes de hostiles. Eliminación de escuadra otorga +60 de munición y +35 de salud.
- **SEARCH & DESTROY (Objective Defense):** Defiende el objetivo explosivo armado en el patio industrial durante 90 segundos frente a escuadras enemigas que intentan desactivarlo en 10 segundos acumulados.

### 5. Settings & In-Game Calibration
- Adjustable display brightness (50% – 200%).
- Field of View slider (60° – 100°).
- Directional shadow map resolution (`Off`, `Low`, `High`).
- Master audio volume control with immediate auditory feedback.
- In-game diagnostics panel (`F3` or `?debug`).

## Technical Architecture

| Component | Implementation |
|---|---|
| **Rendering Engine** | Three.js r160 (Single `THREE.WebGLRenderer`, PCF soft shadow maps, FogExp2) |
| **Language** | Vanilla JavaScript (Native ES2022 Modules, import maps, strict ESM) |
| **Audio** | Web Audio API (Procedural real-time synthesis) |
| **UI Framework** | Zero frameworks. Semantic HTML5, CSS Variables, and CSS `backdrop-filter` |
| **Asset Pipeline** | 100% procedural (Zero binary `.glb` or audio files) |
| **Testing** | Automated CDP & Playwright test suites (34/34 automated tests passing) |
| **Hosting** | GitHub Pages (Static HTTPS CDN delivery) |

## Known Considerations (Alpha)

- **Pointer Lock Security:** Browser security requires an explicit user click gesture on the canvas before raw mouse capture is granted. If pointer lock is interrupted, press `Escape` or click the screen to re-engage.
- **Hardware Acceleration:** Best experienced on desktop browsers with WebGL hardware acceleration enabled.
- **Single-Player Focus:** This initial alpha features single-player combat against AI bots; online multiplayer networking is planned for future milestones.
